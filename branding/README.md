# None Labs Branding UI Kit & Figma 1:1 Layout

> **Convenience in Everyday life**  
> None Labs 공식 브랜드 가이드라인과 Figma 디자인 시스템을 1:1로 추출하여 구축한 순수 UI 컴포넌트 킷 및 프레임 뷰어 저장소입니다.

## 📌 주요 페이지 및 뷰어
1. **[순수 UI 컴포넌트 킷 (`pure_ui_kit.html`)](https://mireu-lab.github.io/none-labs-branding/pure_ui_kit.html)**
   - 임의의 UX / JavaScript 동작을 배제한 순수 UI 마크업 모음.
   - Svelte, React 프론트엔드 작업 시 즉시 컴포넌트화 가능한 7가지 핵심 블록 제공.
2. **[브랜드 레이아웃 허브 (`branding_layout.html`)](https://mireu-lab.github.io/none-labs-branding/branding_layout.html)**
   - 브랜드 시스템, 컬러 팔레트, 타이포그래피, 프레임 목록 및 71개 블록 일람.
3. **[Figma 1:1 전체 캔버스 (`index.html`)](https://mireu-lab.github.io/none-labs-branding/index.html)**
   - 피그마 프레임별 1:1 렌더링 캔버스.
