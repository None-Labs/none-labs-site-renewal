## 🎨 브랜드 디자인 토큰 (Design Tokens)
* **Brand Identity**: `[ None Labs ]` (`Ubuntu` 대괄호 700 Bold, 본문 400 Regular, `#343434`)
* **Slogan**: `Convenience in everyday life` (`Red Hat Display`, `#343434` / `#686868`)
* **Color System**:
  - `Accent / Text`: `#343434`
  - `Secondary Text`: `#686868`
  - `Sub / Muted`: `#888888`
  - `Border / Watermark`: `#DEDEDE`
  - `Surface Gray`: `#E9E9E9`, `#D9D9D9`
  - `Background`: `#F5F5F5`
  - `Card Surface`: `#FFFFFF`
* **Typography Stack**:
  - `Ubuntu`: 브랜드 로고, 코드 태그(`</>`)
  - `Red Hat Display`: 영문 헤드라인, 슬로건, 섹션 타이틀
  - `Pretendard`: 한글 본문, 주소지, 세부 레이블
